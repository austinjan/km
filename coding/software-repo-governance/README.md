# Software Repository Governance

This package helps humans and coding agents enter, understand, change, validate, and resume a software repository without hidden chat context or duplicate sources of truth.

## Start Here

Use [repo-governance-audit](skills/repo-governance-audit/SKILL.md) for repository audits, harness-readiness checks, governance adoption, or requested improvements.

The skill is the single workflow entry point. It owns progressive-disclosure routing for:

- the canonical governance standard;
- guidance for splitting overgrown agent instructions;
- conditional templates for agent routing, progress, constraints, architecture, decisions, and topic instructions.

Read only the references relevant to the current repository evidence. Audit-only requests remain non-mutating; apply templates or other changes only when fixes are explicitly requested.
