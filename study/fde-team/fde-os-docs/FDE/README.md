# FDE

Forward Deployed Engineering practice documents live here.

Use this folder as the main entrypoint for FDE strategy, engagement execution, operating conventions, and reusable reference material.

## Folders

- `strategy/` - why the FDE practice exists, how it creates business value, and how it connects to NIMBL or company strategy.
- `engagement/` - how to run an FDE engagement phase by phase, including gates, outputs, and operating tables.
- `operations/` - how this repository and engagement artifacts should be named, structured, indexed, and maintained.

## Start Here

- `strategy/forward-deployed-engineering.md` - core FDE operating model and strategy memo.
- `engagement/fde-engagement-playbook.md` - full engagement phase playbook.
- `operations/fde-file-and-directory-convention.md` - file naming, directory, and metadata convention.
- `strategy/ceo-business-model-and-nimbl-future.md` - CEO-level business model and NIMBL future framing.
