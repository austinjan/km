# os-config/

Operating system configuration files, shell setup guides, and platform-specific notes.

To set up an OS environment or install utilities, try Claude Code skills first:
- **bash-install-utils** -- Install CLI utilities for bash/zsh
- **nushell-install-utils** -- Install CLI utilities with Nushell integration
- **nushell-config-sync** -- Sync Nushell config between repo and system

## Directories

- `darwin/` -- macOS-specific configuration and setup guides
  - Mac Mini remote development environment (SSH, tmux, Tailscale)
  - Zsh clip-last-command utility
- `nushell/` -- Nushell shell configuration and notes
  - Config file, setup instructions, tips and snippets
- `windows/` -- Windows and WSL configuration
  - WSL Ubuntu development environment setup
  - PowerShell clip-last-command utility
