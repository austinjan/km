# `サクセス` 成功模式攻略

## `サクセス` 成功模式攻略

### 劇本選擇

| 日文原文 | 中文翻譯 | 適合目標 |
|---|---|---|
| `パラレルオールスターズ` | 平行全明星 | 30 周年主打劇本；穿梭歷代成功模式世界、收集同伴。適合先體驗本代主軸。 |
| `World Baseball Classic™ サクセス` | WBC 成功模式 | 與實在選手、侍 Japan 成員互動，目標世界一。適合做二刀流、強投手或國際賽主題球員。 |
| `千将高校 君がキャプテンだ！` | 千將高校：你就是隊長！ | 高校隊長視角，適合想長期玩成功模式架構的玩家。 |
| `サクサクセス` | 速成成功模式 | 走格子短時間做球員；適合補齊 `マイ選手リーグ` 守位。 |

### `パラレルオールスターズ` 策略

- 初期先追求 `修復度`（修復度）高的練習，因為修復時空可拿特殊能力提示與經驗，移動到下一個時空也會回復體力。
- 注意 `時空エネルギー`（時空能量）不要偏科。只做單一高效率練習，可能導致下一個時空能量不足、浪費回合。
- 若目標是高上限球員，後期才根據角色、特殊能力與金特路線微調；初期先把流程跑順。
- `時空間移動`（時空間移動）後的前 3 回合有 `異世界効果`（異世界效果）。Famitsu 的攻略重點是：移動後利用效果練習，修復後立刻轉下一個劇本，不要留在低收益時空拖回合。
- `練習ビッグバン`（練習 Big Bang）需要 `異世界コア`（異世界核心），通常應用在高價值練習、多人 Tag 或修復度高的回合。
- 若已有 `継承選手`（繼承選手），可追高價值金特與青特提示；但序盤不要為了單一提示犧牲太多修復速度。

### `パラレルオールスターズ` 回合優先級

| 優先級 | 看什麼 | 行動 |
|---|---|---|
| 1 | 可否完成時空修復 | 能修復就優先修復，拿經驗、提示與體力回復。 |
| 2 | `時空エネルギー` 是否足夠 | 目標時空缺哪種能量，就補哪種練習，避免卡移動。 |
| 3 | 是否有多人 Tag / Big Bang | 有高價值練習時再投入道具或 Big Bang。 |
| 4 | 體力 | 快修復時可撐一下，因移動會回復；還很久才修復就不要硬練到受傷。 |
| 5 | 金特 / 青特提示 | 中後期再針對角色與繼承選手追提示。 |

### 最推薦模式：`パラレルオールスターズ` 詳細攻略

`パラレルオールスターズ`（平行全明星）是サクセス最推薦先深入玩的模式。理由是：

- 這是 30 周年主打劇本，系統最能代表本作。
- 能做高上限野手、投手、二刀流，也能順便理解歷代サクセス角色。
- 育成核心有明確規則：修復時空、取得 `異世界コア`、使用 `練習ビッグバン`、提高 `時空レベル`、讓 `継承選手` 早點加入。

#### 野手育成流程

| 階段 | 操作 |
|---|---|
| 0-5 ターン | 先到 `あかつき大附属` 追 `四条澄香`；不是最高修復值也可以追一次，目標是早啟動 `ラブパワー`。 |
| 5-15 ターン | 修復速度優先，把 `時空レベル` 推到 5 附近，讓 `継承選手` 加入。 |
| 15-25 ターン | 去 `織田軍` / `聖ジャスミン学園` 拿基礎能力コツ；野手特別重視 `パワー`、`ミート`、守備相關コツ。 |
| 25-40 ターン | 開始根據継承選手與彼女候補追金特 / 青特コツ；高收益 Tag 才開 `練習ビッグバン`。 |
| 40 ターン後 | 到 `パワフルフューチャーズ`、`アオハル学園高校`、`エジプト大学` 等高收益時空，把能力拉上去。 |
| 最終前 | 必要金特 / 青特先買到手，再補基礎能力。不要在很早以前把經驗花光，避免拿到コツ後浪費。 |

野手能力分配：

- 強打型：先確保 `パワー`（力量）、`ミート`（打擊精準）、`弾道`（彈道），再補守備與走力。
- 中線型：二游外野先補 `守備力`（守備力）、`捕球`（接球）、`走力`（跑力），打擊以 `ミート` 和實用青特補穩。
- 捕手型：捕手系特殊能力優先度高於單純長打；自動與試合穩定度都吃捕手能力。

#### 投手育成流程

| 階段 | 操作 |
|---|---|
| 0-15 ターン | 和野手一樣先推修復與時空レベル；若有投手継承選手，越早加入越好。 |
| 15-25 ターン | 先拿投手基礎コツ，特別是球速、コントロール、スタミナ或變化球相關收益。 |
| 25-40 ターン | 看自己定位決定主軸：先發重 `スタミナ`，後援重球威、球速與決勝變化球。 |
| 40 ターン後 | 用 Big Bang 放大高收益投手練習；不要平均點太多球種，先做一個能壓制的主武器。 |
| 最終前 | 補 `奪三振`、`キレ◯`、`ノビ`、`対ピンチ` 類實戰特能，再補細節能力。 |

投手能力分配：

- 先發：`スタミナ` 不可太低，否則再強也撐不住長局數。
- 速球派：球速與 `ノビ` / `怪童` 類相性好。
- 變化球派：至少一個主力變化球要能解決打者，再考慮第二、第三球種。
- 控球派：`コントロール` 與低球、精密機械系能力讓失投風險下降。

#### 經驗點使用規則

| 時期 | 規則 |
|---|---|
| 前 24 ターン左右 | 不急著大量升能力；先等基礎能力コツ與特能コツ，避免點數浪費。 |
| 拿到基礎コツ後 | 優先升對目標最重要的能力，例如強打者的パワー、投手的球速 / 變化球。 |
| 拿到高等特能コツ後 | 高價值金特、實用青特先買，避免後續事件覆蓋或忘記。 |
| 終盤 | 把剩餘經驗轉成星數與實戰能力；不要為了全 S 犧牲必要特能。 |

#### `練習ビッグバン` 使用規則

- `時空レベル` 4 以前：多數情況可以積極使用，目標是快點開更多時空與早點升級。
- `時空レベル` 4 以後：等高收益練習、多人 Tag、`スペシャルタッグ` 或修復值很高的練習再用。
- `パワフルフューチャーズ`：最好帶著足夠 `異世界コア` 進去，前 3 回合連續 Big Bang 的收益很高。
- 不要為了省核心拖慢修復。修復更多時空本身也會帶來經驗與下一顆核心。

#### 試合操作

| 育成類型 | 推薦操作 | 理由 |
|---|---|---|
| 野手 | `自分の打席を操作`（操作自己打席） | 能穩定靠長打與安打拿比賽經驗，風險較低。 |
| 投手 | `チャンスと9回を全員操作`（機會與九局全員操作） | 可避免隊友進攻完全失控，也能保住最終戰勝率。 |
| 不熟操作 | 保守選擇 | 最終戰輸掉會少大量經驗，穩定勝利優先於挑戰高難度操作。 |

#### 常見失誤

- 一開始就把經驗點全花光，後面拿到 `基礎能力のコツ` 才發現浪費了。
- 為了追單一彼女、單一特能或 `センス◯`，在低收益時空停太久。
- `時空エネルギー` 偏科，導致想去的時空去不了。
- `異世界コア` 一直省著不用，結果時空レベル升太慢、継承選手太晚加入。
- 只看單次練習經驗，不看修復值；強選手通常來自「修復更多時空 + 高收益 Big Bang」的總和。
- 最終戰操作太激進。高上限育成最後仍需要贏球收經驗。

### `World Baseball Classic™ サクセス` 策略

- 官方說明此模式有 `バディシステム`（搭檔系統），練習與交流累積 `バディポイント`（搭檔點數）後可做 `師弟スペシャルタッグトレーニング`（師徒特殊雙人訓練）。
- 首日更新加入「滿足條件可育成 `二刀流`（投打二刀流）」功能。若想做二刀流，先確認更新已套用，再把訓練資源分配給投打兩邊。
- 若只是為 `マイ選手リーグ` 補隊伍，不必每次都追求完美金特；先做足守位深度更實用。
- Game8 指出 WBC 起手 `アピールポイント`（展現重點）會改變初始能力；野手若想穩定推進，`長距離ヒッター`（長距離打者）因能靠長打提高比賽貢獻，通常比純速度起手更穩。
- 金特取得重點在 `バディランク`（搭檔等級）：把隊友升到最高等級 `相棒`（搭檔 / 夥伴）後，再參加該選手練習可穩定拿對應金特。
- 二刀流方面，AppMedia 攻略指出需在 WBC 模式中讓大谷翔平成為 `相棒` 並世界一後解放；之後 WBC 成功模式開局選投手，再選 `二刀流`。此條件屬攻略站驗證資訊，非官方頁面逐字說明，遊戲版本更新後仍應再確認。

### WBC 育成路線建議

| 目標 | 日文原文 | 建議 |
|---|---|---|
| 強打野手 | `長距離ヒッター` | 起手就有力量優勢，試合活躍較穩，適合第一次通關。 |
| 速度型野手 | `スピードスター` | 適合外野、二游與盜壘型，但比賽得分壓力較看操作。 |
| 投手 | `投手` | 先確保控球、變化球與體力，再追金特。 |
| 二刀流 | `二刀流` | 解放後再跑；訓練會同時吃投手與野手資源，筋力常不足，要優先補。 |
| 金特收集 | `相棒` | 先鎖定想要金特的隊友，把搭檔等級衝滿。 |
