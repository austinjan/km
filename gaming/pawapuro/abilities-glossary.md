# 特殊能力與名詞對照

## 特殊能力與金特優先級

這裡不是完整特能圖鑑，而是攻略用途的優先表。完整效果仍以遊戲內 `パワプロ辞典`（實況辭典）與攻略站最新表為準。

### 投手推薦

| 日文原文 | 中文翻譯 | 類型 | 優先理由 |
|---|---|---|---|
| `怪童` | 怪童 | 金特 | 速球壓制力高，Game8 將其列為栄冠投手 S 級金特之一。 |
| `驚異の切れ味` | 驚異銳利變化 | 金特 | 變化球壓制力強，常時價值高。 |
| `怪物球威` | 怪物球威 | 金特 | 提高球威，對自動與戰術試合都實用。 |
| `強心臓` | 強心臟 | 金特 | 得點圈有人時強化，危機處理穩。 |
| `ドクターK` | 三振醫生 / Dr.K | 金特 | 兩好球後壓制力提高，體感效果明顯。 |
| `奪三振` | 奪三振 | 青特 | 提高三振能力；多變化球投手尤其好用。 |
| `内角攻め` | 內角攻擊 | 青特 | 可提高 `内角中心` 戰術等級，實戰壓制佳。 |
| `緩急◯` | 緩急佳 | 青特 | 與 `緩急重視` 戰術相性佳。 |
| `リリース◯` | 出手點佳 | 青特 | 也能支援緩急類戰術。 |
| `低め◯` | 低球佳 | 青特 | 支援低球戰術，但 2026 攻略站對低球中心體感評價略保留。 |

### 避免或優先消除的紅特

| 日文原文 | 中文翻譯 | 為什麼麻煩 |
|---|---|---|
| `三振` | 容易三振 | 強打者也會被大量無效打席拖垮。 |
| `エラー` | 容易失誤 | 栄冠與自動對戰中，守備失誤很傷。 |
| `一発` | 容易被全壘打 | 投手紅特，短局面可能直接崩盤。 |
| `負け運` | 敗運 | 投手勝敗與隊伍得分體感差。 |
| `乱調` | 亂調 | 投手穩定度差，自動比賽風險高。 |
| `寸前` | 臨門崩盤 | 接近勝利時掉能力，對先發很傷。 |
