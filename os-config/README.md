# OS Config

Keep all operating system HOWTOs, configuration files, and environment setup notes here.

To set up an environment or install utilities, try asking Claude Code first — we have skills:
- `nushell-config-sync` — sync Nushell config between repo and system
- `nushell-install-utils` — install modern CLI utilities for Nushell
- `bash-install-utils` — install modern CLI utilities for bash/zsh

## Subdirectories

- [darwin/](darwin/) — macOS-specific config (Mac Mini remote dev, zsh tips)
- [windows/](windows/) — Windows 11 and WSL setup (PowerShell tips, WSL2 Ubuntu)
- [nushell/](nushell/) — Nushell shell configuration and setup
